# Basics

Foundational knowledge shared by reading, building, and maintaining SNL libraries.

- [`SNL_DSL.md`](SNL_DSL.md) — `content.snl` grammar, tree structure, binders, styles, and text carriers.
- [`SNL_Macro.md`](SNL_Macro.md) — macro package fields, templates, styles, arity, naming, and escaping.
- [`Json_Schema.md`](Json_Schema.md) — Markdown reference for every `.SNL_Doc` JSON file.

Read the relevant Basics document before a task-specific HowTo guide. Basics explains what the structures mean; HowTo documents explain what work to perform.
