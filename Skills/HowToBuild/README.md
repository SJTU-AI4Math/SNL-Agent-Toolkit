# How to build

Guides for large-scale natural-language → SNL Library construction.

1. [`Document_Workflow.md`](Document_Workflow.md) — select the complete or partial workflow.
2. [`Draft_Document.md`](Draft_Document.md) — create the construction blueprint.
3. [`Design_Terminology.md`](Design_Terminology.md) — choose kinds, packages, and concept ownership.
4. [`Author_Entries.md`](Author_Entries.md) — prefabricate Entries and write macro-first SNL content.
5. [`Construct_Library.md`](Construct_Library.md) — build the Library outline and counter structure.
6. [`Index_Semantics.md`](Index_Semantics.md) — connect macros to defining Entries and external sources.

Before building, read the relevant references under [`../Basics/`](../Basics/README.md).
