# Checklist for SNL 

## For every library:
* [ ] I have ran the linter and no errors are present, the repository is safe for commit.
* [ ] All entry kinds are properly created and can cover the natural language corpus, which the user has agreed on.
* [ ] All entries are properly created, and have undergone entry-level refinements.
* [ ] The tree-structure hierarchy of the library is reasonable and reflects the semantic structure of the natural language corpus.

## For every entry:
* [ ] I have ran the linter and no errors are present, the repository is safe for commit.
* [ ] The snl entry content (if written) reflects the content's semantic structure and is not a trivial syntax tree such as a plain string or a single node.
* [ ] I have checked the entry's SSI (SNL Structural Index) and the number is satisfying, all semantic freedom can be justified.
* [ ] If the entry describes part of the source code in the repository, a pointer pointing to the corresponding source code is provided.
