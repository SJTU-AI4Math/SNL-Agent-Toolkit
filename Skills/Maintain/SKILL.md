# Maintain

`.SNL_Doc` owns the specification. This skill is not yet a complete maintenance
workflow; the only materialized routine is SNL library change reporting.

## Change Reporting

Maintenance edits that add, delete, rename, or move entries change the entry tree;
report them with the shared [SNL Library Change Reporting](../Report/SKILL.md)
reference. Keep the macro content block present and label it "no change" when the
macros did not move. Anything blocked or deliberately skipped is listed
separately from the verified changes.

The canonical specification is the `Skill.Report` Entry family in `.SNL_Doc`.
