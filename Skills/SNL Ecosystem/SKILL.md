# SNL Ecosystem (SNL 生态系统)

## Core Concepts of SNL (SNL 核心概念)

* **Entry (条目)**
  * **Entry Package (条目包)**
  * **Entry Title (条目标题)**
  * **Entry ID (条目 ID)**
    * **Entry ID Namespace (条目 ID 命名空间)**
  * **Entry UUID (条目 UUID)**
  * **Entry Content (条目内容)**
  * **Entry Tag (条目标签)**
  * **Pointer (指针)**
* **Term Macro (术语宏)**
  * **Macro Package (宏包)**
  * **Term Macro Name (术语宏名称)**
  * **Term Macro Kind (术语宏类型)**
    * **Term Macro Namespace (术语宏命名空间)**
  * **Term Macro UUID (术语宏 UUID)**
  * **Term Macro Style (术语宏样式)**
    * **Term Macro Style Tag (术语宏样式标签)**
  * **Term Macro Content (术语宏内容)**
    * **Formula Mode Term Macro (公式模式术语宏)**
    * **Text Mode Term Macro (文本模式术语宏)**
    * **Block Mode Term Macro (块模式术语宏)**
  * **Term Macro Source (术语宏来源)**
  * **Term Macro Tag (术语宏标签)**
* **Library (库)**
  * **Library Title (库标题)**
  * **Library ID (库 ID)**
  * **Library Description (库描述)**
  * **Counter (计数器)**
  * **Reference Tree (引用树)**
  * **HTML Export (HTML 导出)**
* **Entry Kind (条目类型)**
  * **Entry Kind Name (条目类型名称)**
  * **Entry Kind ID (条目类型 ID)**
  * **Entry Kind Description (条目类型描述)**
  * **Entry Kind Coloring (条目类型配色)**
* **Macro Kind (宏类型)**
  * **Macro Kind Name (宏类型名称)**
  * **Macro Kind ID (宏类型 ID)**
  * **Macro Kind Description (宏类型描述)**
  * **Macro Kind Coloring (宏类型配色)**
* **I18N (I18N 国际化)**
  * **UI Language (UI 语言)**
  * **Content Language (内容语言)**
