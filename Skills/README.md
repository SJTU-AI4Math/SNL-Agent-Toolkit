# Skills — task-specific guides

`AGENT.md` is only the entry point. Concrete, self-contained work belongs here.

## Routing

- `document-workflow.md` — choose the phase or partial workflow for a document task.
- `draft-document.md` — produce a construction blueprint before authoring.
- `design-terminology.md` — define Entry Kinds, Macro Kinds, and term macros.
- `author-entries.md` — prefabricate Entries and write macro-first `content.snl`.
- `construct-library.md` — build a Library graph and reading tree.
- `index-semantics.md` — connect macros to defining Entries and URLs.
- `snl-language-rules.md` — syntax and identity rules that apply to all SNL content.
- `use-toolkit-clis.md` — run the shipped lint CLIs and interpret their output.
- `toolkit-workflow-and-roadmap.md` — current execution model and planned CLI work.
- `develop-toolkit.md` — repository implementation and validation conventions.

## Maintenance rule

When a concrete workflow grows or changes, update its document here. Keep `AGENT.md` limited to stable orientation and routing.
